Unified Cache Manager (UCM) 架构总览

持久化 LLM KVCache · 多检索机制替代冗余计算 · 存算分离 PD 分离

核心能力

  • Prefix Cache 前缀缓存命中即跳过 Prefill
  • Sparse Attention 免训练稀疏检索
  • PD Disaggregation 存算分离架构

集成生态

  • vLLM 集成（含 Ascend 适配）
  • SGLang 集成
  • KV Cache 大小计算器 + 故障排查

性能指标

  • 推理延迟降低 3-10 倍
  • 异构资源灵活调度
  • 超长序列推理支持
